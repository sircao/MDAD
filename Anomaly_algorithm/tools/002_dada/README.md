# dada

**Category**: Zero-shot & general models　**Source**: https://github.com/iambowen/DADA

**Overview**: A general anomaly detection model pretrained on multi-domain time series, aimed at being applied to multiple scenarios without domain-specific training.

**Reuse**: Knowledge-retrieval tool (the pretraining code is not public due to IP restrictions; the repo has no complete pretraining pipeline).

**Usage**:
```python
r = get("dada").run()
```
