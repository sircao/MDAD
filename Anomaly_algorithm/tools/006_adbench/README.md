# adbench

**Category**: Benchmarks & datasets　**Source**: https://github.com/Minqi824/ADBench

**Overview**: 30 algorithms and 57 datasets, suitable for horizontal comparison; it is mainly a tabular anomaly detection benchmark and cannot directly represent zero-shot TSAD.

**Reuse**: Knowledge-retrieval tool (benchmark description).

**Usage**:
```python
r = get("adbench").run()
```
